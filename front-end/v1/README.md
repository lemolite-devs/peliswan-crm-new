# Peliswan CRM — v1 (archived)

This is the original front-end (Create React App + MUI), kept for reference.
It is **not deployed**. The live UI is `../v2`.

Use it to look up how a screen or API call worked while moving modules to v2.
It still runs locally if you need to compare behaviour:

```bash
cd front-end/v1
npm start            # → http://localhost:3002 (needs the back-end on :9001)
```

Please don't add features here; build them in v2.
